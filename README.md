# POV: Твоя жизнь на каждом уровне Космодесанта

Анимация кодом (Canvas 2D в Chromium, рендер кадров через Playwright, сборка ffmpeg).

## Стилевые кадры
```
npm install
node scripts/stills.mjs   # -> style/<стиль>-<сцена>.png
```
Стили: `cartoon` (A, мульт-POV), `grimdark` (B), `pixel` (C, пиксель-когитатор).
Предпросмотр в браузере: `src/index.html?style=grimdark&scene=battle&t=1.3` через любой статический сервер из корня репозитория.
